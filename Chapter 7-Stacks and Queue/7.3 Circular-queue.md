## Introduction to Circular Queue

In a regular queue, when you remove items from the front, the positions become empty.

But those empty spots can't be reused.

We can solve this problem using a circular queue.

A circular queue is an improved version of a regular queue where the last position is connected back to the first, forming a circular structure.

In this lesson, you'll learn how to convert a regular queue into a circular queue by making small changes to the enqueue and dequeue methods

## Adding to the Circular Queue

In a regular queue, the enqueue() method looked like this:

```python
def enqueue(self, item):
    if self.is_full():
        print("We can't add elements. The queue is full.")
        return

    self.rear += 1
    self.queue[self.rear] = item
    self.count += 1
```

This works until the rear reaches the end of the list.

After that, you can't insert any more items — even if there are empty slots at the front.

To fix this, we wrap the rear back to the beginning.

Instead of:

```python
self.rear+=1
```

We do this:

```python
self.rear = (self.rear + 1) % self.capacity
```

This wraps the rear to index 0 once it reaches the end.

For example, if the queue size is 5:

If rear = 3, the next rear becomes 4
If rear = 4, the next rear becomes 0 — but only if there's room (i.e. the queue is not full).
Now we can reuse empty space at the front.

Let's implement the above changes to the enqueue() method and visualize how it works in a circular queue.

## Removing from the Circular Queue

Just like we updated the rear pointer for circular behavior, we also need to update the front pointer to wrap around when it reaches the end of the list.

In the regular version, the dequeue method looked like this:

```python
def dequeue(self):
    if self.is_empty():
        print("We can't remove elements. The queue is empty.")
        return None

    item_removed = self.queue[self.front]
    self.queue[self.front] = None
    self.front += 1
    self.count -= 1
    return item_removed
```

To make this circular, we replace:

```python
self.front+=1
```

with

```python
self.front = (self.front + 1) % self.capacity
```

This ensures the front pointer wraps around when needed.

Next, let's update the dequeue() method and visualize how it works in the circular queue.

## Source Code: Circular Queue

```python
class CircularQueue:

    def __init__(self, capacity):
        self.capacity = capacity
        self.queue = [None] * capacity

        self.front = 0  # Points to the item to be removed
        self.rear = -1  # Points to the last inserted item
        self.count = 0  # Number of elements currently in the queue


    def is_full(self):
        return self.count == self.capacity


    def is_empty(self):
        return self.count == 0


    def enqueue(self, item):
        if self.is_full():
            print("We can't add elements. The queue is full.")
            return

        self.rear = (self.rear + 1) % self.capacity
        self.queue[self.rear] = item
        self.count += 1


    def dequeue(self):
        if self.is_empty():
            print("We can't remove elements. The queue is empty.")
            return None

        item_removed = self.queue[self.front]
        self.queue[self.front] = None
        self.front = (self.front + 1) % self.capacity
        self.count -= 1
        return item_removed


    def display(self):
        print(self.queue)
        print(f"Front index: {self.front}, Rear index: {self.rear}, Count: {self.count}")


queue1 = CircularQueue(8)

queue1.enqueue(12)
queue1.enqueue(77)
queue1.enqueue(34)
queue1.enqueue(21)
queue1.enqueue(67)

print("After inserting five elements:")
queue1.display()
print("---")

queue1.dequeue()
queue1.dequeue()

print("After removing two elements:")
queue1.display()
print("---")

queue1.enqueue(45)
queue1.enqueue(73)
queue1.enqueue(65)

print("After inserting three elements:")
queue1.display()
print("---")

queue1.enqueue(54)
print("After inserting one more (should wrap):")
queue1.display()
print("---")
```
